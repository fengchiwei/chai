## 原則

1. **核心功能都要有可重現的測試證據**：四級安全分流、上下文記憶、官方網頁擷取、南投官方資源查詢、真人轉介示範流程。
2. **三種機制分開，不合併**：
   - 薩提爾冰山對話：`engine/dialogue_policy.py`，事件、感受、想法、期待、渴望、自我。
   - 六項身心線索擷取：`engine/wellbeing_signals.py`，持續時間、睡眠、生活功能、人際與壓力、安全線索、支持系統。
   - BSRS-5 自填量表：`engine/bsrs5.py`。
   - 前端沒有顯示某個欄位，不代表後端沒有實作。
3. **以決賽得獎為目標**：優先提高完成度、展示穩定性與可驗證性；暫時不加新模型、動畫或非必要功能。
4. **每次修改後回報**：修改檔案、實際測試結果、未解決問題、哪些功能已能在決賽現場穩定展示。
