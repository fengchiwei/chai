# 學校與輔導室聯絡方式

學生在對話中提到性平事件或霸凌時，不管燈號，畫面都會出現「🏫 可以找學校輔導室談談」卡片：
- 說明輔導室可以幫忙，以及學校接到後會怎麼處理（性平：24 小時內通報、身分保密、113；霸凌：啟動防制霸凌處理、1953）。
- 一張可以修改的轉介單（只寫主題，不抄學生說過的話）。
- 學生願意說學校時，幫他找出學校的聯絡方式。**系統不會代寄、不會打電話，也不會儲存學生輸入的學校。**

聯絡資料分兩層：

| 資料 | 檔案 | 內容 | 涵蓋範圍 |
|---|---|---|---|
| 教育部學校名錄 | `data/schools_moe.json` | 學校總機、地址、官網 | 全台 4,022 所公私立學校：國小 2,609、國中 740、高中職 506、特殊教育學校 28、大專校院 139（115 學年） |
| 核對過的輔導室信箱 | `data/school_counseling.json` | 輔導室信箱（可另附輔導室電話） | 團隊親自核對的學校，目前 0 所 |

- 名錄**沒有**輔導室分機或信箱，所以一般學校的卡片顯示「📞 學校總機（接通後說要找輔導室）」和「🌐 學校網站」，並註明資料來自教育部統計處各級學校名錄。
- 只有在第二層有資料的學校，才會出現「✉️ 用我自己的信箱開好草稿」：只會打開學生自己的郵件程式，要不要寄由學生決定。
- 同名學校（例如全台有好幾間「中正國小」）會先選南投縣那間，並列出其他同名學校讓學生改選；沒有南投縣的就讓學生從清單挑。

## 更新教育部名錄

每學年教育部統計處更新「各級學校名錄」後（約 8 月），在專案資料夾執行：

```bash
python scripts/import_moe_schools.py --year 116
```

需要 `openpyxl`（只有這支腳本用到，網站本身不需要）。來源頁：https://depart.moe.edu.tw/ED4500/News.aspx?n=63F5AB3D02A8BBAC&sms=1FF9979D10DBF9F3

## 加入核對過的輔導室信箱

**只放團隊親自核對過的資料，不可猜測或自行組合信箱。** 每一筆都要有：

| 欄位 | 必填 | 說明 |
|---|---|---|
| `name` | ✅ | 學校名稱，寫法與名錄相同最穩，例如「國立南投高中」 |
| `code` | | 名錄裡的學校代碼；有填就以代碼對應 |
| `aliases` | | 其他常用簡稱 |
| `office` | | 預設「輔導室」，有些學校叫「輔導處」 |
| `email` | ✅ | 輔導室公開的聯絡信箱（Gmail 或學校網域都可以） |
| `phone` | | 輔導室電話或分機 |
| `source_url` | ✅ | 學校官網上寫著這個信箱的頁面，必須是 `https://` |
| `verified_on` | ✅ | 核對日期，例如 `2026-10-23` |

缺少必填欄位、信箱格式錯誤或來源不是 https 的資料會被自動略過（有測試檢查）。

```json
{
  "schools": [
    {
      "name": "（學校名稱）",
      "code": "（名錄代碼，選填）",
      "office": "輔導室",
      "email": "（官網公開的輔導室信箱）",
      "phone": "（輔導室電話）",
      "source_url": "https://（官網上寫著信箱的頁面）",
      "verified_on": "2026-10-23"
    }
  ]
}
```

網路搜尋找不到南投各校公開的輔導室信箱（多數學校只公布電話分機），所以第二層目前是空的。決賽前可以先向合作學校確認信箱與公開頁面後再加入。
