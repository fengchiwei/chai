# 學校輔導室信箱名單（`data/school_counseling.json`）

學生在對話中提到性平事件或霸凌時，不管燈號，畫面都會出現「🏫 可以找學校輔導室談談」卡片：
- 說明輔導室可以幫忙，以及學校接到後會怎麼處理（性平：24 小時內通報、身分保密、113；霸凌：啟動防制霸凌處理、1953）。
- 一張可以修改的轉介單（只寫主題，不抄學生說過的話）。
- 學生願意說學校時，若名單裡有那間學校，就能按「✉️ 用我自己的信箱開好草稿」：只會打開學生自己的郵件程式，要不要寄由學生決定。**系統不會代寄，也不會儲存學生輸入的學校。**

## 名單規則

**只放團隊親自核對過的資料，不可猜測或自行組合信箱。** 每一筆都要有：

| 欄位 | 必填 | 說明 |
|---|---|---|
| `name` | ✅ | 學校全名，例如「國立南投高級中學」 |
| `aliases` | | 學生常用的簡稱，例如「南投高中」；至少 3 個字，太短的簡稱不會比對 |
| `office` | | 預設「輔導室」，有些學校叫「輔導處」 |
| `email` | ✅ | 輔導室公開的聯絡信箱（Gmail 或學校網域都可以） |
| `phone` | | 輔導室電話或總機分機 |
| `source_url` | ✅ | 學校官網上寫著這個信箱的頁面，必須是 `https://` |
| `verified_on` | ✅ | 核對日期，例如 `2026-10-23` |

缺少必填欄位、信箱格式錯誤或來源不是 https 的資料會被自動略過（有測試檢查）。

## 範例

```json
{
  "schools": [
    {
      "name": "（學校全名）",
      "aliases": ["（常用簡稱）"],
      "office": "輔導室",
      "email": "（官網公開的輔導室信箱）",
      "phone": "（輔導室電話）",
      "source_url": "https://（官網上寫著信箱的頁面）",
      "verified_on": "2026-10-23"
    }
  ]
}
```

## 目前狀態

名單目前是空的：網路搜尋找不到南投各校公開的輔導室信箱（多數學校只公布電話分機）。名單空的時候，學生仍會看到卡片與轉介單，查不到學校時畫面會建議把轉介單印出或抄下來，直接拿到輔導室或請導師轉交。決賽前請團隊向合作學校確認信箱與公開頁面後再加入。
