# 青少年生活知識 Harness 開發計畫（2026-10-23；P0–P2 已於 v2.8 完成）

## 一、要解決的問題

> 範圍更新（2026-10-23）：紓壓只是其中一例。學生也會問讀書方法、升學資訊去哪查、霸凌、家人吵架、網路安全、電子煙、打工權益、怎麼約心理諮商等問題，所以知識庫擴大為五大面向：情緒與壓力、學習與升學、人際與安全、身體與健康、權益與求助。主題清單在 `data/knowledge/topics.json`，新增面向只要加主題與卡片，不用改程式。


學生問「怎麼紓壓」「考前睡不著怎麼辦」「一直滑手機停不下來」這類問題時，現在的回覆只靠 AI 模型本身的知識。這有三個問題：

- **可能過時**：模型的知識有截止日，不知道最新的建議或資源。
- **沒有出處**：學生和老師都看不出建議從哪裡來。
- **品質不穩定**：可能給出沒有根據、不適合青少年，甚至有風險的方法。

「Harness」指包在 AI 外面的一層：先找到可信、最新的資料，再讓 AI 根據這些資料用學生聽得懂的話回答，並附上出處。AI 不再憑記憶回答。

## 二、設計原則

1. **安全先於新鮮**：橙色、紅色的安全回合不使用這層；危機一律走現有的安全流程與求助電話。
2. **只用白名單來源**：政府與公衛機關、醫學會、大學與研究機構、同儕審查的回顧文章。不用論壇、商業部落格或社群貼文。
3. **人審過才上線**：自動抓到的新資料先進「待審」，由工作臺的輔導人員或管理員核可後才給學生看，符合計畫書「中高風險由真人判斷」的精神。
4. **不提供醫療處置**：延續 v2.7 的 `medical_advice` 檢查；用藥、診斷相關的資料不收錄。
5. **一定附出處**：每則建議都帶來源名稱、網址與查核日期；回覆引用的來源必須是這次提供給 AI 的資料，不能自己編。
6. **在地化**：優先台灣的資料與資源（衛福部、國健署、教育部、南投縣衛生局），國外資料要轉成適合台灣國高中生的說法。

## 三、架構

```
學生訊息
  │
  ├─ 安全分流（現有）── 橙／紅 ──▶ 安全流程，不查資料
  │
  └─ 綠／黃，且是在問方法（support_choice）或問資訊（answer_question：「電子煙有什麼影響」「15 歲可以打工嗎」）
        │
        ▼
   ① 主題判斷（topics.json 的 hints）：五大面向、約 40 個主題
        │
        ▼
   ② 檢索：在「已核可的知識卡」中找最相關的 1–3 張（本機，不連網）
        │                      ▲
        │                      │ 核可
        ▼               ⑤ 工作臺審核頁 ◀── ④ 每週更新工作：抓白名單來源 → AI 整理成卡片草稿
   ③ 把卡片當「參考資料」放進提示詞
        │
        ▼
   AI 寫回覆 → 送出前檢查（引用必須來自提供的卡片、不能有用藥建議）
        │
        ▼
   學生看到回覆，下方附「資料來源」連結
```

### 知識卡（資料單位）

每張卡是一個小而具體、經過核可的方法，例如「4-7-8 呼吸」「考前一晚的睡眠準備」：

| 欄位 | 說明 |
|---|---|
| `id`、`title`、`topics` | 例如 `sleep-before-exam`、「考前一晚怎麼睡得比較好」、`["睡眠","考試"]` |
| `steps` | 2–4 個學生可以自己做的步驟（白話、具體） |
| `suitable_for` | 國中、高中、兩者皆可；有沒有不適合的情況 |
| `avoid` | 不要這樣做的提醒（例如「不要自行吃安眠藥」→ 改成「睡不好很久要找醫師」） |
| `evidence` | 證據等級：官方指引、系統性回顧、單一研究、專家意見 |
| `sources` | 來源名稱、網址、發布或更新日期、查核日期 |
| `status` | `draft`（待審）、`approved`（已核可）、`retired`（下架） |
| `reviewed_by`、`reviewed_at`、`expires_at` | 誰核可、何時核可、何時要重新檢查（預設 12 個月） |

### 檢索方式

- 先用**本機、不連網**的檢索：知識卡最多幾百張，不需要向量資料庫。
- 用中文字詞與主題標籤做 BM25 關鍵字比對，加上主題判斷的加權即可。
- 好處：不多花錢、不多等，也不會把學生的訊息送到另一家服務。
- 卡片超過一千張或效果不好時，再評估加入文字向量（embedding）。

### 「最新資料」從哪來

| 方式 | 做法 | 優點 | 缺點 |
|---|---|---|---|
| A. 定期更新（建議先做） | 每週排程抓白名單網站的更新，AI 整理成卡片草稿，人審後上線 | 安全、可控、回覆不變慢 | 新資料最快也要等審核 |
| B. 即時搜尋（選用） | 學生問到知識卡沒有的主題時，即時搜尋白名單網域，結果只當參考、標示「未經審核」 | 涵蓋面廣、最新 | 要多付搜尋 API 費用、回覆變慢、品質較難控制 |

建議先做 A；B 等 A 穩定、專業人員審閱過後再決定。若做 B，學生的原話不直接送給搜尋服務，只送主題關鍵字。

## 四、要新增或修改的檔案

| 位置 | 內容 |
|---|---|
| `data/knowledge/sources.json` | 來源白名單：名稱、網域、信任等級、語言、檢查週期 |
| `data/knowledge/topics.json` | 五大面向與主題、每個主題的學生說法（hints） |
| `data/knowledge/cards.json` | 知識卡（含 draft／approved／retired） |
| `engine/knowledge.py` | 主題判斷、BM25 檢索、挑卡片、組成提示詞的參考資料段落 |
| `engine/dialogue_ai.py` | `turn_task()` 在綠、黃色且是在問方法時加入「參考資料卡」；送出前檢查引用 |
| `engine/dialogue_reply.py` | 新檢查 `invented_source`：回覆提到的來源必須在本輪卡片裡 |
| `scripts/refresh_knowledge.py` | 定期更新：抓白名單來源、比對是否有更新、請 AI 產生卡片草稿（只進 draft） |
| `app.py` | `/api/knowledge`（工作臺列出、核可、下架卡片；管理員與輔導人員都可審）；聊天回應加上 `sources` |
| `templates/counselor.html`、`static/js/knowledge.js` | 工作臺「📚 知識卡審核」頁：看草稿與原文出處、修改、核可或退回 |
| `static/js/app.js` | 學生回覆下方顯示「資料來源」連結（只顯示來源名稱與網址） |
| `tests/test_knowledge_*.py`、`tests/knowledge_eval.jsonl` | 單元測試與 50 題評估集；接進 9.5 分閘門 |
| GitHub Actions 或 Render Cron Job | 每週執行一次 `refresh_knowledge.py` |

## 五、開發階段（約 8 週）

| 階段 | 週數 | 工作 | 產出與完成條件 |
|---|---|---|---|
| P0 規劃與來源 ✅ v2.8 | 第 1 週 | 列出主題清單（約 15 個）與白名單來源；訂卡片格式；決定第六節的問題 | `sources.json`、主題清單、卡片範本 |
| P1 首批知識卡 ✅ v2.8（78 張） | 第 2–3 週 | 人工（AI 輔助）整理 30–50 張卡，每張都有出處；請輔導人員初審 | `cards.json`（approved ≥ 30 張） |
| P2 檢索與整合 ✅ v2.8 | 第 3–4 週 | `engine/knowledge.py`、提示詞整合、引用檢查、學生頁顯示來源 | 綠、黃色問方法時會引用卡片；安全回合完全不受影響 |
| P3 評估 | 第 5 週 | 50 題評估集（含不該觸發、危機、用藥陷阱題）；接進閘門 | 命中率 ≥ 85%、引用正確率 100%、安全違規 0、回覆時間增加 < 0.5 秒 |
| P4 自動更新與審核頁 | 第 6–7 週 | `refresh_knowledge.py`、工作臺審核頁、排程 | 新資料只進草稿；核可、下架都留操作紀錄 |
| P5 專業審閱與上線 | 第 8 週 | 用 `docs/PROFESSIONAL_REVIEW.md` 請專業人員看卡片內容；修正後上線 | 審閱紀錄、v2.8 發布 |
| P6 即時搜尋（選用） | 之後 | 方式 B，限白名單網域、只送主題關鍵字 | 另行評估費用與風險後再決定 |

## 六、需要先決定的事

1. **要不要做即時搜尋（方式 B）？** 建議先只做定期更新。
2. **誰審核知識卡？** 建議輔導人員帳號都可以審，至少一位專業人員抽查。
3. **白名單來源**：建議起點如下，請團隊與指導老師增刪。
   - 衛福部心理健康司
   - 國健署
   - 教育部學生事務及特殊教育司
   - 南投縣衛生局
   - 台灣精神醫學會、台灣臨床心理學會、台灣諮商心理學會
   - 世界衛生組織（WHO）
   - 美國國家心理衛生研究院（NIMH）
   - 英國國民保健署（NHS）
   - Cochrane 系統性回顧
4. **更新與費用**：定期更新每週約呼叫 AI 數十次來整理草稿，費用很低；即時搜尋則依搜尋 API 計費。

## 七、風險與對策

| 風險 | 對策 |
|---|---|
| 抓到錯誤或不適合青少年的內容 | 只用白名單；一律人審後才上線；卡片有到期日，到期自動下架待複查 |
| AI 編造來源或改寫成錯誤建議 | 只能引用本輪提供的卡片；`invented_source` 與 `medical_advice` 檢查；評估集抽查 |
| 學生把方法當成治療、延誤就醫 | 卡片附「持續兩週以上或影響上學，請找輔導老師或醫師」；黃色以上照常提供求助管道 |
| 危機時反而給紓壓技巧 | 橙、紅色完全不查資料；評估集有危機題，觸發即算失敗 |
| 來源網站改版或失效 | 更新工作檢查網址狀態，失效就通知管理員並暫停該卡 |
| 回覆變慢 | 本機檢索（毫秒級）；不在聊天當下連網 |
